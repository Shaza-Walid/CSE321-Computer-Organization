## 🧪 Lab 1 – Introduction to MIPS Assembly

Lab 1 introduces the basics of MIPS Assembly programming and working with the QtSPIM simulator.

**Task Requirements:**

Write a MIPS Assembly program that prints the following information:

```text
Name:   Your Name
ID:     Your ID
Course: CSE321-Computer-Organization
```

The program uses MIPS system calls to print strings to the console.
