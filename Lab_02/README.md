# MIPS Assembly - Lab 2

Lab 2 covers basic arithmetic operations, conditional statements, loops, and switch-case implementation.

## 📂 Lab Exercises

### 1. Add Two Numbers

* Read two integers from the user.
* Calculate their sum.
* Display the result.

### 2. If Condition

* Read an integer from the user.
* Check whether the number is positive, negative, or zero.
* Display the appropriate message.

### 3. While Loop

* Print the numbers from 1 to 10 using a `while` loop.

### 4. Do-While Loop

* Read integers from the user.
* Calculate their sum until the user enters `0`.
* Display the final sum.

### 5. For Loop

* Calculate the sum of the first `n` natural numbers using a `for` loop.

**Task 1: Average of Four Integers**

* Read four integers from the user.
* Calculate their average.
* Display the result with an appropriate message.

**Task 2: Average of n Integers**

* Ask the user to enter the number of integers `n`.
* Read `n` integers from the user.
* Calculate their average.
* Display the result with an appropriate message.

**Task 3: Switch-Case**

* Implement switch-case functionality using MIPS Assembly.
* Execute different operations based on the user's choice.
