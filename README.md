# CSE321 – Computer Organization

This repository contains my lab exercises, section work, and task solutions for the **CSE321 – Computer Organization** course at Zagazig University.

The lab exercises are implemented using **MIPS Assembly Language** and executed using **QtSPIM**.

## 📁 Repository Structure

```text
CSE321-Computer-Organization/
├── labs/
│   ├── lab1/
│   │   ├── sectionWork.asm
│   │   ├── taskWork.asm
│   │   └── screenshots/
│   ├── lab2/
│   └── ...
└── README.md
```

## 🛠️ Tools & Technologies

- **Language:** MIPS Assembly
- **Simulator:** QtSPIM
- **Version Control:** Git & GitHub

## ▶️ How to Run the Programs

1. Install and open QtSPIM.
2. Open the required `.asm` file.
3. Load the assembly program.
4. Run the program using the simulator.
5. Check the console output.
6. Save a screenshot of the execution in the corresponding `screenshots/` directory.
